# Open Human Sensing Interoperability Framework

Status: Pre-alpha / proposal-stage repository

This repository hosts an open-source interoperability framework for multimodal human sensing data in ageing, rehabilitation, exoskeleton, wearable computing, and behavioral health research.

The project aims to provide:
- shared data schemas
- synchronization tools
- annotation standards
- AI-ready data pipelines
- interoperability with existing sensing and analysis ecosystems
